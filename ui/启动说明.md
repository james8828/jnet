# 病理图像智能分析系统 - 启动指南

## 🚀 快速开始

### 前置要求
- Node.js >= 18.0.0
- npm >= 9.0.0 或 yarn >= 1.22.0

### 第一步：安装依赖

打开终端，进入 ui 目录：

```bash
cd E:\doc\system-admin\ui
```

安装项目依赖：

```bash
npm install
```

或使用 yarn：

```bash
yarn install
```

### 第二步：启动开发服务器

```bash
npm run dev
```

启动成功后，终端会显示：

```
VITE v5.0.0  ready in 1234 ms

➜  Local:   http://localhost:3000/
➜  Network: use --host to expose
```

在浏览器中访问 **http://localhost:3000** 即可看到系统界面。

### 第三步：构建生产版本

当开发完成后，构建生产版本：

```bash
npm run build
```

构建产物将生成在 `dist` 目录中。

### 第四步：预览生产构建

```bash
npm run preview
```

## 🔧 常见问题

### Q1: 安装依赖时出错？

**解决方案：**
1. 清除 npm 缓存：
   ```bash
   npm cache clean --force
   ```
2. 删除 node_modules 和 package-lock.json：
   ```bash
   rm -rf node_modules package-lock.json
   ```
3. 重新安装：
   ```bash
   npm install
   ```

### Q2: 端口 3000 被占用？

**解决方案：**
修改 `vite.config.ts` 中的端口配置：
```typescript
server: {
  port: 3001,  // 改为其他端口
}
```

### Q3: 如何修改 API 代理地址？

**解决方案：**
在 `vite.config.ts` 中修改 proxy 配置：
```typescript
proxy: {
  '/api': {
    target: 'http://your-backend-server:8080',  // 修改这里
    changeOrigin: true
  }
}
```

### Q4: 如何实现真实的图像标注功能？

**需要集成：**
1. OpenSeadragon - 用于 SVS 高清图像查看
2. Fabric.js - 用于 Canvas 交互式标注
3. 后端 API - 保存和加载标注数据

示例代码已在注释中提供。

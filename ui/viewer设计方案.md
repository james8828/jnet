#### 2.2 几何布尔运算（⭐核心新增）

##### 2.2.0 两种运算模式对比

**模式 A：基于选择的运算（精确模式）**
- **适用场景**：对已存在的多个标注进行运算
- **操作流程**：多选标注 → 选择运算类型 → 预览 → 确认
- **优点**：精确可控，可预览结果
- **缺点**：需要先有完整的标注

**模式 B：基于绘制的运算（快速编辑模式）** ⭐推荐
- **适用场景**：编辑单个标注时快速扩展或裁剪
- **操作流程**：选中目标 → 选择绘制运算工具 → 直接绘制 → 松开即生效
- **优点**：流畅自然，类似 Photoshop 蒙版操作
- **缺点**：需要手绘，精度依赖用户操作

##### 2.2.1 并集 (Union)

###### 模式 A：基于选择的并集
**交互流程：**
1. 进入"编辑模式"
2. 按住 `Ctrl` 多选两个及以上重叠标注
3. 点击工具栏"几何运算 → 并集"
4. 预览：半透明虚线显示合并结果
5. 确认：生成新标注，删除原始标注

**技术实现：**
```typescript
// 使用 turf.js 或 jsts 库进行几何运算
import * as turf from '@turf/turf'

const unionAnnotations = (features: Feature[]) => {
  const geometries = features.map(f => f.getGeometry())
  let result = geometries[0]
  
  for (let i = 1; i < geometries.length; i++) {
    result = turf.union(
      turf.feature(result),
      turf.feature(geometries[i])
    ).geometry
  }
  
  return result
}
```

**使用场景：**
- 将多个分散的肿瘤区域合并为一个完整病灶
- 合并多次绘制的同一组织结构

---

###### 模式 B：绘制并集（⭐编辑模式专用）
**交互流程：**
1. 进入"编辑模式"，单击选中一个目标标注
2. 点击工具栏"绘制并集"工具（图标：⊕）
3. 在地图上直接绘制新的多边形（与目标部分重叠）
4. **松开鼠标立即生效**：新绘制区域自动合并到目标标注
5. 自动生成一个新的合并后的标注，原标注被更新

**视觉反馈：**
- 绘制过程中：新图形用绿色虚线显示（表示将要添加的区域）
- 目标标注：保持高亮选中状态
- 松开鼠标：短暂闪烁动画提示合并成功

**技术实现：**
```typescript
// 在 useAnnotationInteractions.ts 中新增
const setupDrawUnion = () => {
  if (!map.value || !vectorSource.value) return
  clearInteractions()

  const targetFeature = selectInteraction!.getFeatures().item(0)
  if (!targetFeature) {
    ElMessage.warning('请先选择一个目标标注')
    return
  }

  drawInteraction = new Draw({
    source: vectorSource.value,
    type: 'Polygon',
    freehand: true, // 自由绘制模式
    style: new Style({
      stroke: new Stroke({ color: '#67C23A', width: 3 }), // 绿色虚线
      fill: new Fill({ color: '#67C23A33' })
    })
  })

  drawInteraction.on('drawend', async (event) => {
    const newGeometry = event.feature.getGeometry()
    const targetGeometry = targetFeature.getGeometry()

    try {
      // 执行并集运算
      const unionGeom = turf.union(
        turf.feature(targetGeometry),
        turf.feature(newGeometry)
      ).geometry

      // 更新目标标注
      targetFeature.setGeometry(unionGeom)
      
      // 移除临时绘制的图形
      vectorSource.value!.removeFeature(event.feature)
      
      // 保存到后端
      await confirmEdit()
      ElMessage.success('并集操作成功')
    } catch (error) {
      ElMessage.error('并集运算失败')
      vectorSource.value!.removeFeature(event.feature)
    }
  })

  map.value.addInteraction(drawInteraction)
}
```

**使用场景：**
- **快速扩展标注边界**：医生发现肿瘤区域遗漏了一小块，直接用绘制并集补上
- **增量式标注**：分多次绘制复杂形状，逐步完善
- **修正不完整标注**：在已有标注基础上快速添加缺失部分

**优势对比：**

| 特性 | 基于选择的并集 | 绘制并集 |
|------|--------------|---------|
| 操作步骤 | 5步（多选→点击→预览→确认） | 3步（选中→绘制→自动完成） |
| 适用对象 | 多个已存在的标注 | 单个标注 + 手绘区域 |
| 精确度 | 高（基于已有标注） | 中（依赖手绘） |
| 速度 | 较慢 | **极快** |
| 编辑场景 | 批量合并 | **实时修正** |

**使用场景：**

- 去除坏死区域后的活性组织标注

###### 模式 B：绘制差集（⭐编辑模式高频使用）
**交互流程：**
1. 进入"编辑模式"，单击选中一个目标标注
2. 点击工具栏"绘制差集"工具（图标：⊖，快捷键：`D`）
3. 在目标标注上直接绘制要删除的区域
4. **松开鼠标立即生效**：绘制区域从目标中挖去
5. 如果绘制区域完全在目标外，提示"无重叠区域"

**视觉反馈：**
- 绘制过程中：新图形用红色虚线显示（表示将要删除的区域）
- 目标标注：保持高亮，未删除部分半透明显示
- 松开鼠标：挖去区域闪烁后消失，剩余部分更新

**技术实现：**
```typescript
// 在 useAnnotationInteractions.ts 中新增
const setupDrawDifference = () => {
  if (!map.value || !vectorSource.value) return
  clearInteractions()

  const targetFeature = selectInteraction!.getFeatures().item(0)
  if (!targetFeature) {
    ElMessage.warning('请先选择一个目标标注')
    return
  }

  drawInteraction = new Draw({
    source: vectorSource.value,
    type: 'Polygon',
    freehand: true, // 支持自由绘制和规则图形
    style: new Style({
      stroke: new Stroke({ color: '#F56C6C', width: 3 }), // 红色虚线
      fill: new Fill({ color: '#F56C6C33' })
    })
  })

  drawInteraction.on('drawend', async (event) => {
    const cutGeometry = event.feature.getGeometry()
    const targetGeometry = targetFeature.getGeometry()

    try {
      // 检查是否有重叠
      const hasOverlap = turf.booleanIntersects(
        turf.feature(targetGeometry),
        turf.feature(cutGeometry)
      )

      if (!hasOverlap) {
        ElMessage.warning('绘制区域与目标标注无重叠')
        vectorSource.value!.removeFeature(event.feature)
        return
      }

      // 执行差集运算
      const diffGeom = turf.difference(
        turf.feature(targetGeometry),
        turf.feature(cutGeometry)
      )

      if (!diffGeom) {
        ElMessage.warning('差集运算结果为空（可能完全切除）')
        vectorSource.value!.removeFeature(event.feature)
        return
      }

      // 更新目标标注
      targetFeature.setGeometry(diffGeom.geometry)
      
      // 移除临时绘制的图形
      vectorSource.value!.removeFeature(event.feature)
      
      // 保存到后端
      await confirmEdit()
      ElMessage.success('差集操作成功')
      
      // 控制台输出调试信息
      console.log('[DrawDifference] 差集运算完成', {
        originalArea: turf.area(turf.feature(targetGeometry)),
        removedArea: turf.area(turf.feature(cutGeometry)),
        remainingArea: turf.area(diffGeom)
      })
    } catch (error) {
      console.error('[DrawDifference] 差集运算失败:', error)
      ElMessage.error('差集运算失败')
      vectorSource.value!.removeFeature(event.feature)
    }
  })

  map.value.addInteraction(drawInteraction)
}
```

**使用场景：**
- **快速挖洞**：在肿瘤标注中挖去血管、坏死区
- **修剪边界**：切除标注超出组织边界的多余部分
- **创建空心结构**：如腺体的腔隙、血管的空腔
- **精细调整**：比顶点编辑更快地去除大块区域

**实际案例：**
```
场景：医生标注了一片肿瘤组织，但中间有几个血管不应该包含在内

传统方式：
1. 退出编辑模式
2. 手动绘制每个血管的多边形
3. 多选所有血管标注
4. 选择目标肿瘤标注
5. 点击"差集"按钮
6. 确认操作
→ 共 6 步操作

绘制差集方式：
1. 保持编辑模式，选中肿瘤标注
2. 点击"绘制差集"工具
3. 直接在血管位置涂抹（可连续多次绘制）
4. 每次松开鼠标自动挖去
→ 共 2 步操作，效率提升 3 倍
```

**高级特性：**
1. **连续绘制模式**：一次激活可连续绘制多个差集区域，按 `Esc` 退出
2. **撤销支持**：每次差集操作都可单独撤销
3. **智能吸附**：绘制时自动吸附到目标边界，保证切割整齐
4. **面积阈值**：可设置最小切除面积（如 <10px² 忽略），避免误操作

**优势对比：**

| 特性 | 基于选择的差集 | 绘制差集 |
|------|--------------|---------|
| 操作步骤 | 6步（绘制→多选→点击→确认） | 2步（选中→绘制） |
| 适用对象 | 多个已存在的标注 | 单个标注 + 手绘区域 |
| 灵活性 | 低（需预先绘制减数） | **极高**（即时绘制） |
| 速度 | 慢 | **极快** |
| 编辑体验 | 割裂（切换多次工具） | **流畅**（一站式完成） |
| 学习成本 | 中 | 低（直观易懂） |

**用户反馈模拟：**
> "绘制差集功能太实用了！以前要在肿瘤里挖掉血管，我得先画好血管的标注，再做差集运算，至少要操作五六次。现在直接用红色笔刷涂一下就好了，就像在 Photoshop 里用橡皮擦一样自然。" —— 病理科医生

```typescript
const bufferAnnotation = (feature: Feature, distance: number) => {
  const buffered = turf.buffer(
    turf.feature(feature.getGeometry()),
    distance,
    { units: 'pixels' }
  )
  return buffered.geometry
}
```

#### 3.2 快捷键设计

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `V` | 选择工具 | 切换到选择模式 |
| `P` | 多边形绘制 | 切换到自由绘制 |

| `I` | 绘制交集 | 编辑模式下快速激活 |
| `Delete` | 删除选中 | 删除当前选中标注 |

**快捷键设计原则：**

### 七、性能优化策略

1. **虚拟渲染**
    - 只渲染视口内的标注
    - 使用 OpenLayers 的 `declutter` 选项

2. **Web Worker**
    - 几何运算放到 Worker 线程
    - 避免阻塞主线程

3. **增量更新**
    - 布尔运算时只更新受影响的标注
    - 避免全量刷新

4. **LOD（Level of Detail）**
    - 低倍率时显示简化几何
    - 高倍率时显示完整细节

### 4. 技术风险控制

**风险1：几何运算性能问题**
- **缓解措施：** 
  - 使用 Web Worker 执行复杂运算
  - 对超大标注（>5000顶点）先简化再运算
  - 设置超时机制，避免长时间阻塞

**风险2：Turf.js 库体积过大**
- **缓解措施：**
  - 按需引入模块（tree-shaking）
  - 考虑轻量级替代方案（如 flatgeobuf）
  - CDN 加载，非首屏必需

**风险3：浏览器兼容性**
- **缓解措施：**
  - 测试主流浏览器（Chrome、Firefox、Edge、Safari）
  - 提供降级方案（如不支持 Web Worker 则同步执行）
  - 明确最低浏览器版本要求

# 病理图像标注系统 - 交互模式与功能使用手册

## 1. 系统概述

本系统是基于 Vue3 + OpenLayers 开发的 Web 端全切片病理图像（WSI）标注工具。系统采用**“只读优先”**的设计理念，确保用户在浏览海量病理数据时的安全性，同时提供专业级的标注编辑能力。

---

## 2. 核心交互模式

### 2.1 默认状态：只读模式 (Read-Only Mode)
当用户进入 Viewer 页面时，系统自动处于**只读模式**。
*   **视觉反馈**：鼠标滑过已存在的标注图形时，指针会变为“手型”（Pointer），提示该对象可被选中。
*   **操作限制**：
    *   点击标注仅触发**高亮选中**（红色边框）。
    *   **禁止**拖拽移动图形。
    *   **禁止**修改顶点形状。
    *   **禁止**误触导致的意外保存。
*   **适用场景**：快速浏览切片、查看已有标注分布、核对标注信息。

### 2.2 编辑模式 (Edit Mode)
用户需手动点击工具栏的 **“编辑”** 按钮进入。
*   **激活功能**：
    *   **整体拖拽**：按住选中的标注任意位置即可平移整个图形。
    *   **顶点微调**：拖动图形边缘的白色控制点，改变多边形或线条的形状。
*   **确认机制**：
    *   **自动保存**：松开鼠标完成拖拽或调整后，系统会自动计算精度并同步至后端。
    *   **快捷键支持**：支持 `Enter` 键确认保存，`Esc` 键取消修改并恢复原状。
    *   **右键菜单**：在编辑状态下点击鼠标右键可直接触发保存。

### 2.3 绘制模式 (Drawing Mode)
包括“绘点”、“自由绘线”和“自由绘制”。
*   **画笔体验**：采用 `Freehand` 技术，用户只需**按住鼠标左键拖动**即可连续绘制，无需逐点点击。
*   **实时反馈**：绘制过程中，笔触颜色会自动匹配当前选中的标签颜色。
*   **智能简化**：系统会在后台自动对自由绘制的密集轨迹进行几何简化（Simplify），在保证形状精度的前提下大幅减少数据存储量。

## 3. 工具栏功能详解

### 3.1 基础工具组
| 工具名称 | 图标/文字 | 交互描述 | 快捷键/技巧 |
| :--- | :--- | :--- | :--- |
| **选择** | 选择 | 切换至只读模式。点击标注可查看属性、执行复制或删除。 | 点击空白处取消选中 |
| **绘点** | 绘点 | 在地图指定位置标记一个点（如细胞核中心）。 | 单击即完成绘制 |
| **自由绘线** | 自由绘线 | 绘制开放的路径（如血管走向）。按住拖动绘制，松开结束。 | 增加 10px 点击容差，易于选中 |
| **自由绘制** | 自由绘制 | 绘制闭合的多边形区域（如肿瘤边界）。按住拖动绘制，松开自动闭合。 | 自动填充半透明颜色 |
| **编辑** | 编辑 | 开启顶点的增删改及图形的整体平移功能。 | 选中后直接拖拽 |

### 3.2 几何运算与管理组
*   **填充 (Padding)**：对选中的多边形进行内部填充运算（具体算法视后端实现而定）。
*   **复制 (Stickup)**：将选中的标注在原位或指定位置克隆一份。**注意**：此操作由后端驱动，确保 ID 唯一性。
*   **删除 (Delete)**：永久移除选中的标注。系统会弹出二次确认框防止误删。

### 3.3 历史记录组
*   **撤销 (Undo)**：回退上一步操作。
*   **重做 (Redo)**：恢复被撤销的操作。

### 3.4 标签管理组
*   **标签选择器**：下拉菜单选择当前标注所属的类别（如：肿瘤、炎症、坏死等）。
*   **颜色联动**：不同的标签 ID 对应不同的显示颜色（蓝、绿、橙、红、灰循环），便于视觉区分。

## 4. 详细操作流程

### 4.1 如何添加一个新标注？
1.  在工具栏右侧选择一个**标签**（例如：“肿瘤区域”）。
2.  点击工具栏左侧的 **“自由绘制”** 按钮。
3.  在地图上找到目标区域，**按住鼠标左键**沿边界拖动。
4.  回到起点附近**松开鼠标**，图形自动闭合。
5.  系统提示“标注保存成功”，并在左侧列表刷新显示。

### 4.2 如何调整一个已有标注的位置？
1.  确保当前处于 **“选择”** 模式，点击你想移动的标注使其变红。
2.  点击工具栏的 **“编辑”** 按钮。
3.  将鼠标移到红色标注上，指针变为“十字”或“移动”状。
4.  **按住左键拖动**到合适位置。
5.  **松开鼠标**，系统自动保存新坐标。

### 4.3 如何修正标注的形状？
1.  进入 **“编辑”** 模式并选中目标标注。
2.  你会看到图形周围出现了多个**白色小圆点**（顶点）。
3.  拖动任意白点即可拉伸或收缩局部形状。
4.  调整完毕后，按键盘 **`Enter`** 键或点击鼠标**右键**确认保存。
5.  若调整失误，按 **`Esc`** 键可立即恢复到调整前的状态。

## 5. 高级特性与技术细节

### 5.1 坐标精度控制
*   **规范**：所有前端产生的坐标数据均强制保留**两位小数**。
*   **目的**：平衡病理图像的超高分辨率需求与数据库存储压力，避免浮点数过长导致的性能问题。

### 5.2 像素坐标系 (Pixel Coordinate System)
*   **说明**：本系统不使用经纬度（EPSG:4326），而是直接使用图像的**像素坐标**。
*   **优势**：避免了复杂的投影转换误差，确保标注点在任意缩放级别下都能精准对齐组织切片。

### 5.3 智能点击容差 (Hit Tolerance)
*   **设置**：系统为选择和拖拽交互设置了 **10 像素**的感应范围。
*   **效果**：即使是非常纤细的自由绘线，用户也不需要精确点到那 1px 宽的线上，点在附近即可触发选中或拖拽。

### 5.4 样式渲染规范
*   **动态样式**：标注的颜色不是写死的，而是根据 `tagId` 动态计算得出。
*   **透明度处理**：多边形填充色采用 10%-20% 的透明度，确保用户在下层依然能看清病理组织结构。

## 6. 常见问题排查 (FAQ)

**Q: 为什么我点击线条没有反应？**
A: 请确认你是否已经点击了工具栏的 **“选择”** 按钮。如果处于绘制模式下，点击事件会被绘图工具拦截。

**Q: 为什么我拖动标注后它又弹回去了？**
A: 这通常是因为网络请求失败或后端校验未通过。请检查浏览器控制台的 `Network` 面板，查看 `updateAnnotation` 接口是否返回了错误信息。

**Q: 自由绘制的线条太粗糙怎么办？**
A: 系统默认使用了 2 像素的简化容差。如果需要更精细的轮廓，可以在代码中调整 `geometry.simplify()` 的参数。

**Q: 如何查看某个标注的具体属性？**
A: 在“选择”模式下点击标注，控制台会输出该要素的完整 Properties 对象，包含 `annotationId`, `tagId`, `area` 等信息。

## 7. 开发者调试指南

在浏览器控制台（Console）中，你可以使用以下命令实时监控交互状态：

```javascript
// 查看当前激活的工具
console.log('Current Tool:', window.__viewerInstance.getCurrentTool());

// 查看当前选中的标签 ID
console.log('Selected Tag ID:', window.__viewerInstance.getSelectedTagId());

// 获取地图上所有的标注要素
const features = viewer.vectorSource.getFeatures();
console.log('Total Annotations:', features.length);

// 强制重新加载标注
window.__viewerInstance.loadAnnotations();
```

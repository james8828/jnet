通过检索安装目录，发现 UI 有两层验证机制：

**1. 浏览器兼容性检测**
- 检测 `User-Agent` 是否包含 `MSIE` 和 `Trident` 标识
- 要求使用 MSIE 7.0 兼容性模式
- 证据：[index.php](file:///d:/work/nova/NovaNet%20v3.6.12.15%20SP12/Apache2/htdocs/index.php) 中的 UA 示例

**2. UI 服务状态检测**
- 数据库表 `DBA.authorized_services` 中 `enabled` 字段必须为 `'T'`
- 反编译的 [NNBase.cs](file:///d:/work/nova/NovaNet%20v3.6.12.15%20SP12/decompile/NNClass/NNBase.cs) 中的 `CheckIfAuthorized()` 方法会强制检查
- 如果未授权，会调用 `LibWrap.ExitProcess(0u)` 终止进程

```
Mozilla/4.0 (compatible; MSIE 7.0; Windows NT 6.1; WOW64; Trident/6.0; SLCC2; .NET CLR 2.0.50727; .NET4.0C; .NET4.0E; .NET CLR 3.5.30729; .NET CLR 3.0.30729)
```

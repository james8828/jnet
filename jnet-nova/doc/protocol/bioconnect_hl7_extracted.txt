Introduction 
Bio-Connect is designed to act as an intermediary between individual hospital sources 
(ADT/diagnostic test results) (Hospital Information Systems – HIS, or Laboratory 
Information Systems - LIS) and the other device/instruments. Bio-Connect will 
receive ADT records from the individual hospital ADT source via HL7 messages and 
capture test results from device/instruments and sent the result to LIS/HIS system via 
HL7 messages. The details of this interface will be discussed between Bio-Connect 
and the individual hospital. Bio-Connect will filter and standardize the ADT/Result 
messages as appropriate when sending them to other device/instruments/LIS. The 
details of this second interface are the subject of this document. 
 
The following provides a simplified data flow diagram of Bio-Connect 
 
The system will receive HL7 version 2.4  messages via a TCP/IP socket and the HL7 
minimal lower layer protocol  as the basis for the Interface, and will acknowledge 
every message received and not accept another message until an acknowledgement 
message has been returned to the sender. The acknowledgement message will indicate 
the receipt and completion of processing of an HL7 message, and prompt the sender

Outbound Acknowledgement Message 
Receipt of an ADT message into Bio-Connect will return a communication 
acknowledgement to the sending system with message segments MSH and MSA, 
respectively. In addition, The acknowledgement message send by Bio-Connect 
contains the MESSAGE CONTROL ID of the message originally sent by ADT 
system. Bio-Connect will not process any application level error messages, nor will it 
process any delayed acknowledgement messages.
